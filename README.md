# WATTSUN – AI-Based Solar Energy Optimization System

Predicts rooftop solar generation and recommends optimal appliance usage timing.

## Dataset
- Kaggle: Solar Power Generation and Meteorological Data
  https://www.kaggle.com/datasets/fastpredictor/solar-power-generation-and-meteorological-data
- Live data: NASA POWER API (solar radiation), Weather API (temp/cloud cover/humidity/wind)

## Tech Stack
- Frontend: React.js
- Backend: FastAPI (Python)
- DB: PostgreSQL
- ML: Random Forest Regressor (Scikit-learn, Pandas, NumPy)
